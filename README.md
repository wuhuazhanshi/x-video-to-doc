# X 视频转写与精读

把 X / Twitter 帖子链接发给支持 Agent Skills 的助手，即可按视频整理出中文精读和原语言逐字稿。精读中的重要观点标有原片时间，方便回到视频核对。演示或无对白视频可以按时间记录画面。

## 安装与使用

在支持从 GitHub 导入技能的客户端，导入本仓库。手动安装时，将含有 [SKILL.md](./SKILL.md) 的 `x-video-to-doc` 目录放入客户端的技能目录并启用。

发送一条具体的帖子链接即可，也可以一次发多条。同帖多段视频分别整理，各自从零计时。要指定保存位置，可以随链接附一句“保存到我的访谈笔记知识库”。

## 运行条件

助手需要能访问原片、字幕或用户上传的媒体。现成字幕可直接用于校对。需要本地识别时，运行环境可配备 yt-dlp、FFmpeg（含 ffprobe）和 faster-whisper。仓库提供技能说明，媒体工具和识别模型由运行环境提供。

## 输出

每条视频对应一篇文档，依次包含原帖和片序、带时间的中文精读、原语言逐字稿或画面记录，并列明转写来源和覆盖范围。支持写入知识库的客户端可保存后返回文档链接。其他环境可交付 Markdown。
